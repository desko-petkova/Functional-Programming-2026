## Втора учебна версия
 1. Изтеглена ръка от разбърканите плочки
 2. Изчисляваме стойността на всички плочки без LINQ
 3. Правим собствен Where функция
 ```csharp
    static List<Tile> FilterTiles(List<Tile> hand, Func<Tile, bool> condition)
    {
    List<Tile> result = new List<Tile>();

    foreach (Tile tile in hand)
    {
        if (condition(tile))
        {
            result.Add(tile);
        }
    }

    return result;
    }
 ```

4. Задачи с FilterTiles() :
    - изведете всички червени плочки от ръката на играча
    - изведете всички плочки със стойност над 7
    - изведете всички плочки равни на 8

## Трета учебна версия

    - всички червени плочки;
    - всички плочки с номер над 7;
    - всички плочки с номер 8.

Пример:

```csharp
List<Tile> redTiles = hand
    .Where(tile => tile.Color == TileColor.Red)
    .ToList();
```
 2. Изчислете общата стойност на всички плочки в ръката чрез Sum().
 3. Създайте нов списък, който съдържа само числата на плочките от ръката.
 4. LINQ pipeline - Намерете сумата само на червените плочки.   Where → Select → Sum
 5. Използвайте LINQ, без foreach, за да:
    - намерите всички сини плочки;
    - намерите всички плочки с номер над 10;
    - намерите сумата само на сините плочки;
    - получите списък само с числата на плочките;
    - преброите колко плочки са с номер над 10.
  6. Отложено изпълнение
  Създайте LINQ заявка:
```csharp
IEnumerable<Tile> query = hand
```

##  Четвърта учебна версия
 Да използваме LINQ и малки отделни функции за реализиране на реална игрова логика в Rummikub – проверка дали дадена комбинация от плочки е валидна **група** или **редица**.

---

1. Проверка за валидна група

В Rummikub **група** е комбинация от:

- 3 или 4 плочки;
- с еднакъв номер;
- с различни цветове.

Пример за валидна група:

```text
Red 8
Blue 8
Black 8
```

Пример за невалидна група:

```text
Red 8
Red 8
Blue 8
```

Напишете функция:

```csharp
static bool IsValidGroup(List<Tile> tiles)
```

Тя трябва да връща `true`, ако комбинацията е валидна група.

Подходящи LINQ методи:

```csharp
Count()
All()
Select()
Distinct()
```

---

2. Проверка за валидна редица

В Rummikub **редица** е комбинация от:

- поне 3 плочки;
- плочки от един и същи цвят;
- последователни номера.

Пример за валидна редица:

```text
Blue 4
Blue 5
Blue 6
Blue 7
```

Пример за невалидна редица:

```text
Blue 4
Blue 6
Blue 7
```

Напишете функция:

```csharp
static bool IsValidRun(List<Tile> tiles)
```

Преди проверката подредете плочките по номер:

```csharp
List<Tile> ordered = tiles
    .OrderBy(tile => tile.Number)
    .ToList();
```

След това проверете дали всеки следващ номер е точно с `1` по-голям от предишния.

---

3. Проверка за еднакъв цвят

Използвайте LINQ метода `All()`:

```csharp
bool sameColor = tiles
    .All(tile => tile.Color == tiles[0].Color);
```

Обсъдете:

- какво проверява `All()`;
- какъв тип функция приема;
- защо резултатът е `bool`.

---

4. Проверка за еднакъв номер

Използвайте:

```csharp
bool sameNumber = tiles
    .All(tile => tile.Number == tiles[0].Number);
```

Сравнете този подход с:

```csharp
tiles
    .Select(tile => tile.Number)
    .Distinct()
    .Count() == 1;
```

Обсъдете как двата варианта решават една и съща задача по различен начин.

---

5. Проверка за различни цветове

За валидна група цветовете не трябва да се повтарят.

Използвайте:

```csharp
int differentColors = tiles
    .Select(tile => tile.Color)
    .Distinct()
    .Count();
```

Сравнете броя на различните цветове с броя на плочките.

---

## Задача 6. Комбиниране на проверки

Функцията:

```csharp
static bool IsValidGroup(List<Tile> tiles)
```

трябва да комбинира следните условия:

```text
брой плочки
+
еднакъв номер
+
различни цветове
```

Целта е отделните проверки да се комбинират в едно по-сложно поведение.

---

7. Проверка на редица като pipeline

Преобразувайте плочките до подреден списък от числа:

```csharp
List<int> numbers = tiles
    .OrderBy(tile => tile.Number)
    .Select(tile => tile.Number)
    .ToList();
```

След това проверете:

```text
numbers[1] == numbers[0] + 1
numbers[2] == numbers[1] + 1
...
```

Самата проверка за последователност може да бъде реализирана с цикъл.

> Функционалният стил не означава, че всичко задължително трябва да бъде написано с LINQ.

---

 8. Обща проверка на комбинация

Напишете функция:

```csharp
static bool IsValidCombination(List<Tile> tiles)
```

Тя трябва да връща `true`, ако комбинацията е:

```text
валидна група
ИЛИ
валидна редица
```

Пример:

```csharp
static bool IsValidCombination(List<Tile> tiles)
{
    return IsValidGroup(tiles) || IsValidRun(tiles);
}
```
