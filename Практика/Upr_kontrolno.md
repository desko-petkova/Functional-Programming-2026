**Упражнение за контролно по функционално програмиране**

**Задача 1. Изчисления чрез чисти функции**

Реализирайте методите:

```csharp
static decimal CalculateArea(decimal width, decimal height)
static decimal CalculatePerimeter(decimal width, decimal height)
static decimal ApplyDiscount(decimal price, decimal discountPercent)
```

Методите трябва да получават необходимите данни чрез параметри и да връщат резултат. Въвеждането и извеждането реализирайте в `Main`.

Проверете ги със следните данни:

- правоъгълник със страни `5` и `8`;
- цена `120` и отстъпка `15%`.

---

**Задача 2. Операции чрез делегати**

Създайте ламбда изрази, записани в променливи от подходящ тип:

- `square` — намира квадрата на цяло число;
- `isEven` — проверява дали цяло число е четно;
- `sum` — събира две цели числа;
- `getMessage` — връща текста `"Обработката приключи."`;
- `print` — извежда подаден текст.

Използвайте `Func`, `Predicate` и `Action`. Извикайте всеки делегат поне веднъж.

**Задача 3. Подаване на операция**

Реализирайте метода:


Чрез него и подходящи ламбда изрази изчислете:

- квадрата на `7`;
- утроената стойност на `12`;
- числото `25`, намалено с `8`;
- остатъка при деление на `37` на `10`.

**Задача 4. Собствено филтриране**

Реализирайте метод, който връща **нов списък** с числата, отговарящи на подаденото условие:

```csharp
static List<int> Filter(
    List<int> numbers,
    Func<int, bool> condition)
```

В тази задача не използвайте LINQ.

Използвайте списъка:

```csharp
List<int> numbers = new() { -8, 3, 12, 0, -5, 7, 18, 4 };
```

Чрез отделни извиквания на `Filter` получете:

- положителните числа;
- четните числа;
- числата, по-големи от `5`;
- числата в интервала от `0` до `10` включително.

Първоначалният списък трябва да остане непроменен.

**Задача 5. Собствено преобразуване**

Реализирайте метод, който прилага подадена операция върху всяко число и връща резултатите в **нов списък**:

```csharp
static List<int> Transform(
    List<int> numbers,
```

В тази задача не използвайте LINQ.

```csharp
List<int> numbers = new() { 2, -3, 5, -7, 10 };
```

Получете отделни списъци с:

- квадратите на числата;
- удвоените им стойности;
- абсолютните им стойности.

**Задача 6. Обработка на числа с LINQ**

Даден е списъкът:

```csharp
List<int> numbers = new() { 14, -3, 8, 21, 0, -6, 8, 5, 12 };
```

Използвайте `Where`, `Select`, `Sum` и `ToList`, за да:

1. Създадете списък с отрицателните числа.
2. Създадете списък с числата, кратни на `3`.
3. Създадете списък с квадратите на положителните числа.
4. Създадете списък с четните числа, увеличени с `100`.
5. Намерите сумата на числата, по-големи от `10`.
6. Намерите сумата от квадратите на отрицателните числа.

Изведете всички резултати.

**Задача 7. Обработка на думи**

```csharp
    "делегат", "метод", "програма", "клас"

```

Чрез LINQ:

1. Получете думите с поне `6` символа.
2. Получете думите, започващи с `"п"`.

Изведете резултатите, без да променяте първоначалния списък.

**Задача 10. Комплексна задача „Анализ на оценки“**

Използвайте списъка:

```csharp
List<double> grades = new()
{
    5.50, 2.00, 6.00, 4.50, 3.00, 5.75, 2.50, 4.00
};
```

Реализирайте програма, която:

1. Записва в `Func<double, bool>` условие за оценка поне `5.50`.
2. Използва делегата с `Where`, за да получи отличните оценки.
3. Получава отделен списък с оценките под `3.00`.
4. Преобразува оценките в точки чрез формулата:

   ```csharp
   points = grade * 10;
   ```

5. Намира сумата на всички получени точки.
6. Използва `Action<double>` за извеждане на всяка отлична оценка с два знака след десетичния разделител.

Първоначалният списък трябва да остане непроменен.
