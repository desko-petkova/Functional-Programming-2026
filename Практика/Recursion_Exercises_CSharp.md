# Упражнение: обикновена и опашкова рекурсия с C#

## Цел

Да сравните кога се изчислява резултатът, как се използва акумулатор и какво показва стекът на извикванията.

## Указания

Реализирайте задачите чрез **статични методи**, без цикли и LINQ. Извиквайте методите от `Main()`.

За всяка задача създайте две реализации:

- **Обикновена рекурсия** — след рекурсивното извикване остава операция.
- **Опашкова рекурсия** — резултатът от рекурсивното извикване се връща директно, без допълнителни операции след него. Натрупаната стойност се предава чрез параметър **акумулатор**.

## Задача 1. Сума от 1 до n

Напишете методи, които намират сумата на целите числа от `1` до `n`. Приемете, че `0 ≤ n ≤ 100`.

```csharp
static int Sum(int n)
{
    // Допишете.
}

static int SumTail(int n, int accumulator = 0)
{
    // Допишете.
}
```

### Насоки

- Дъното на рекурсията е при `n == 0`.
- При обикновената рекурсия добавете `n` към резултата от подзадачата.
- При опашковата рекурсия подайте натрупаната сума на следващото извикване.

### Проверка

| n | Очакван резултат и от двата метода |
|---:|---:|
| 0 | 0 |
| 1 | 1 |
| 5 | 15 |
| 10 | 55 |

**Проследете ръчно `Sum(3)` и `SumTail(3)`. Отбележете кога се извършва всяко събиране.**

```csharp
static int Power(int number, int exponent)
{
    // Допишете.
}

static int PowerTail(
    int number, int exponent, int accumulator = 1)
{
    // Допишете.
}
```

### Насоки

- Всяко допустимо число на степен `0` е `1`.
- При всяко рекурсивно извикване намалявайте степента с `1`.
- Основата `number` остава същата.
- Опашковата реализация предава натрупаното произведение.

### Проверка

| number | exponent | Очакван резултат |
|---:|---:|---:|
| 2 | 0 | 1 |
| 2 | 5 | 32 |
| 3 | 4 | 81 |
| 5 | 3 | 125 |

**Какво ще се случи, ако началната стойност на акумулатора е `0`? Обяснете защо.**

## Задача 3. Сума на цифрите

```csharp
static int SumDigits(int number)
{
    // Допишете.
}

static int SumDigitsTail(int number, int accumulator = 0)
{
    // Допишете.
}
```

Използвайте:

```csharp
number % 10 // Последната цифра

```

### Насоки

- Дъното на рекурсията е при `number == 0`.
- Подзадачата обработва числото без последната цифра.
- В опашковата реализация добавяйте последната цифра към акумулатора.

### Проверка

|---:|---:|

| 507 | 12 |
| 9999 | 36 |

## Задача 4. Наблюдение в Call Stack

Използвайте методите от задача 1.

1. Поставете breakpoint в дъното на `Sum`.
2. Стартирайте `Sum(4)` в **Debug**.
3. Отворете **Debug → Windows → Call Stack**.
4. Разгледайте стойността на `n` в отделните кадри.
5. Повторете за `SumTail(4)` и разгледайте също `accumulator`.

Отговорете:

- Колко активни извиквания на съответния метод виждате?
- Каква работа остава след рекурсивното извикване в `Sum`?
- Каква работа остава след него в `SumTail`?
- Защо и при опашковата реализация може да виждате множество кадри?

**Важно:** опашковата форма не гарантира оптимизация на стека в C#.
